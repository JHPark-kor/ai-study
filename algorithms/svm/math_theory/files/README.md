# SVM Handwritten Notes

SVM 수학 원리 공부 중 작성한 손필기 사진, 수식 이미지, PDF를 저장하는 폴더입니다.

## What Goes Here?

아래 같은 파일을 넣습니다.

- 손으로 쓴 수학 노트 사진
- 태블릿 필기 이미지
- 여러 장을 묶은 PDF
- 발표 때 사용한 수식 캡처

## File Name Rule

```text
svm_내용_작성자_번호.확장자
```

예시:

```text
svm_kkt_pjh_01.jpg
svm_hyperplane_jaesung_01.jpg
svm_margin_wjddbsl03_01.pdf
```

이미지를 넣은 뒤에는 상위 [README.md](../README.md)의 `Handwritten Notes` 표에도 링크를 추가합니다.
