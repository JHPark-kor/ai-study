# SVM Analysis Files

W8 보고서 PDF 3개, 실행 결과가 저장된 노트북 3개, Notion 본문 3개와 강재성의 프로젝트 ZIP을 보존합니다. [분석 기록과 요약](../README.md)

- PDF·IPYNB·ZIP은 원본 바이트를 유지하고 작성자를 포함한 W8 파일명으로 통일했습니다. 노트북과 ZIP 안의 코드는 실행하지 않았습니다.
- Markdown은 원래 상태·담당자·첨부 표시명을 유지하고 링크 경로만 조정했습니다. 박중현 본문의 `구버전`은 Notion 첨부 표시명이며, 보고서의 완성도를 새로 판정한 표현이 아닙니다.
- 박중현 PDF의 원래 이름은 `w3_svm_anlaysis_박중현.pdf`, 신정윤 노트북은 `w3_svm_emotion_detection.ipynb`입니다. 실제 W8 개인 과제에 첨부된 자료를 기준으로 주차를 정리했습니다.
- 강재성 프로젝트 ZIP에는 코드·설명·집계 결과 CSV가 있으며 SECOM 원자료는 포함되어 있지 않습니다. ZIP 안의 노트북과 별도로 첨부된 노트북은 동일 파일이 아니므로 둘 다 보존했습니다.
