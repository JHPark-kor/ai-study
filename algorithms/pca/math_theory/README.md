## Core Summary

스터디가 끝난 뒤, 핵심만 짧게 정리합니다.

- PCA는 데이터의 분산이 가장 큰 방향을 찾는다.
- 첫 번째 주성분은 데이터를 가장 잘 퍼뜨려 보여주는 방향이다.
- 고유값은 해당 방향이 설명하는 분산의 크기를 의미한다.
- 고유벡터는 주성분 방향을 의미한다.
