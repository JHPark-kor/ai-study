## 박중현 · 문화예술 관람 의향

- 국민문화예술활동조사 2023~2025년 자료를 통합해 뮤지컬 관람 의향과 문화자본·문화 접점의 관계를 살펴봤습니다.
- 성인 응답자 28,779명 중 결측 43행을 제외하고, PC 구조 탐색과 베이지안 네트워크 학습을 진행했습니다.
- 평가 결과는 AUC 0.7570, Brier score 0.0928이며, 부트스트랩으로 변수군별 설명량 차이를 검토했습니다.
- 문화자본·문화 접점의 합산 설명량이 더 컸지만 직접관람 연결을 제외하면 차이가 뚜렷하지 않아, 분석 결과가 네트워크 설정에 민감함을 확인했습니다.

## 강재성 · 반도체 공정 불량 분류

- SECOM의 생산 표본 1,567개를 이용해 Gaussian Naive Bayes로 양품과 불량을 구분했습니다.
- 학습 데이터에서 고결측·상수 변수를 제거하고 중앙값 대체·표준화를 적용했으며, 교차검증으로 `var_smoothing=0.5`를 선택했습니다.
- 테스트 불량 21개 중 14개를 검출했고, 균형 정확도 0.6797과 ROC-AUC 0.7290을 얻었습니다.
- 양품 90개를 불량으로 판단한 결과를 함께 살펴보며 불량 누락을 줄이는 효과와 추가 검사 부담 사이의 절충을 해석했습니다.

## 신정윤 · 신용카드 연체 예측 구조 설계

- UCI 신용카드 고객 30,000명의 자료로 다음 달 연체를 설명하는 베이지안 네트워크를 설계했습니다.
- 범주 재분류, 파생 변수 생성, 학습 데이터 기준 이산화를 거쳐 전문가 구조와 Hill Climbing의 BIC·K2 구조를 비교했습니다.
- Naive Bayes를 포함한 구조별 MLE·라플라스 평활 확률표를 학습하고 모델 유효성을 검사했습니다.
