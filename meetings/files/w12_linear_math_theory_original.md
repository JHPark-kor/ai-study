### 내용

<aside>

- 볼록함수는 그래프 위의 임의의 두 점을 연결한 선분보다 함수값이 아래에 있거나 같은 함수이다. **모든 지역 최솟값이 전역 최솟값**이므로 최적화 결과를 해석하기 쉽다. 미분 가능한 볼록함수에서는 기울기가 0인 점이 전역 최소점이지만, 최적해가 반드시 하나인 것은 아니다.
- 닫힌 해
    - 정해진 식에 값을 대입하여 직접 계산하는 해 (ex.이차방정식의 근의 공식)
    - 선형 회귀는 조건이 충족되면 적용 가능
    - 반복적으로 값을 수정하는 **경사하강법**과 구별
- 로그 선형 회귀
    - 지수 형태의 관계를 로그 변환으로 선형 관계로 표현
- 일반화 선형 모델(GLM)
    - 로그 선형 회귀의 확장
    - **출력의 조건부 평균과 입력의 선형 결합을 링크 함수로 연결**
    - 로지스틱 회귀에서는 오즈의 로그인 로짓을 링크 함수로 사용하며, 이를 확률에 대해 풀면 시그모이드 함수가 된다.
</aside>

### 주제

1. 로지스틱 회귀 
</aside>

### 내용

<aside>

- 분류모델
- 시그모이드 함수: 선형 결합 점수 Z를 0과 1사이의 연속적인 값으로 변환, 링크 함수 역할
- 로그 오즈(log odds)
    - odds = p / 1-p (클래스 1이 나올 상대적 비)
    - p = 1 / 1+e^-z → p / 1-p = e^z로 변환 (시그모이드 적용)
    - 자연로그화 하여 z = wTx + b의 선형결합 함수로 변환
    - **편의점에서 할아버지께 담배를 계산**
- 학습
    - y =1일때 예측확률 p도 커지도록 학습 (y = 0 일 때는 반대)
    - 최대우도추정(MLE): 관측 값(정답)의 가능도를 가장 크게 하도록 하는 파라미터 결정
    - 우도 최대화 = 음의 로그 우도 최소화
</aside>

1. 선형 회귀와 최소제곱법
</aside>

### 내용

<aside>

- 선형모델
    - 속성들의 선형 조합을 통해 예측하는 함수를 학습하는 모델
- 선형회귀
    - 최대한 정확하게 실제 데이터를 예측하는 선형 모델 학습하는 것을 목표
- 단순선형회귀
    - 속성이 단 1개인 선형회귀
    - D = {(x_i, y_i)}(i=1~m)
- f(x) = w*x_i + b 에서 w, b 추정
    - 최소제곱법:
    f(x)(예측값)와 y(실제값) 간의 차이를 최소화하는 방법
    - E(w, b)를 각각 w와 b에 대해 편미분하여 w와 b의 추정값을 구함
- 유클리드 거리
    - 두 점 사이의 거리를 피타고라스 방식으로 구함
    - 최소제곱법과의 관계
    : 관측값 벡터, 예측값 벡터 사이의 유클리드 거리의 제곱 = SSE
    제곱근은 단조증가 함수로 거리최소화와 거리제곱최소화의 해가 동일함 (유클리드 거리 사용)
</aside>

### 내용

<aside>

**다중선형회귀**

- 다중선형회귀
    - 속성이 2개 이상인 선형 회귀
    - D = {(x_i, y_i)}(i=1~m), x_i = (x_i1; x_i2; ,,, ; x_id)
    x_i는 i번째 샘플에서의 각 속성값을 의미함
- 행렬 표현
    - hat(w) = (w;b)
    - D = m x (d+1) 크기의 행렬 X
    (이때, d+1에서 1인 원소는 절편 b를 구하기 위함)
- 단순선형회귀와 동일한 방식으로 최적의 hat(w)를 구함(식 3.10)

**풀랭크 행렬과 X^T * X**

- 풀랭크 행렬
    - 행렬 A (m×n)가 rank(A) = min(m, n)이면 풀랭크
    가능한 최대 계수를 가지며, 행(또는 열)이 서로 선형독립인 행렬
- 풀랭크가 아닌 경우
    - 다중공선성 (서로 독립이지 않은 속성 존재)
    - 변수의 수 > 샘플의 수
    
    → 무수히 많은 해가 존재하게 됨
    
- 해결방법
    - 정규화(regularization): w의 norm이 가장 작은 해를 선택함
</aside>
